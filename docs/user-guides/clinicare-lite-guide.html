User guide

Getting around ClinicCare‑Lite

A clinic's admin and communication hub: health tasks in, reviewed submissions out, and a quiet channel between patient and clinician in between.

＋ This system never diagnoses, interprets symptoms, or recommends treatment. Any automated check on a submission only confirms a form was filled in correctly — nothing more.

Installation

Run this from inside the clinicare-lite/ folder.

terminal
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000 in a browser.

Registering

  1. Select Register, then choose whether you're a Clinician or a Patient.
  2. Enter your 8-digit ID: clinicians end in 0000, patients end in their registration year, 2022–2028 — e.g. 12340000 or 12342024.
  3. Patients only: enter the clinician ID of the clinic you're joining — a clinician must have already registered.
  4. Enter your name, email, and a password: 8+ characters with an uppercase letter, lowercase letter, digit, and special character (!@#$%^&*).
  5. Log in with your new ID and password.

Two guides in one

What you see depends entirely on which role you registered as.

Clinician

Assigns, reviews, and keeps the clinic informed

Dashboard
Patient count, task count, pending-review count, recent announcements.
+ New health task
Title, instructions, due date, assign to a registered patient — optionally list expected CSV/TXT column names for the structural completeness check.
Submissions
Filter by task, patient, or status. Preview shows a CSV as a table or a TXT as plain text. Review sets a categorical outcome — Pending, Reviewed — Normal, Needs Follow-up, Escalated — plus notes; the patient is notified automatically.
Messages
One non-urgent thread per patient.
Announcements
Post a clinic-wide notice, optionally emailed to every patient.
Appointments
Schedule and update status — feeds the no-show-rate analytic.
Analytics
Clinic-wide aggregates only: completion rate, pending reviews, turnaround, no-show rate, monthly volume. Never a per-patient comparison.
Patient

Submits, reads outcomes, and tracks their own progress

My Tasks
Every task assigned to you, its due date and status. Submit or resubmit a .txt, .csv, or .pdf file — 5 MB max.
Structural check
A note if a file looks incomplete, e.g. a missing expected column — a form check, never a medical read.
Review outcomes
Appear directly on your task list once a clinician reviews your submission.
Messages
A non-urgent thread with your clinic's clinician.
My Progress
Private engagement points, on-time/late completion, appointment attendance — visible only to you, never compared with anyone else.
Theme
Toggle dark / colorful from the sidebar at any time.
Both messaging threads carry the same standing notice: not monitored continuously, not for emergencies.

If something goes wrong

BlockedA weak password, malformed ID, or duplicate account ID is rejected with a clear message before anything is saved.
BlockedAn unsupported file type, an empty file, or a file over 5 MB is rejected before it's stored.
DeniedReaching for another patient's task, submission, or conversation — even by guessing a URL — returns a permission page, not the data.
DeniedReaching a clinician-only or patient-only page as the wrong role is blocked the same way.
