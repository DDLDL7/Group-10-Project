# Group 10 Project — CS 112 Final Course Project

Three related, independent builds in one repo:

1. **[grid-analysis/](grid-analysis/)** — Python data science project analyzing a synthetic Ghana electricity grid dataset (pandas, NetworkX, Folium, Streamlit).
2. **[gridcare-lite/](gridcare-lite/)** — Python desktop app (PySide6 + SQLite) for utility outage/maintenance management.
3. **[clinicare-lite/](clinicare-lite/)** — Python web app (Flask + JSON files) for clinic patient admin and communication.

Each component is a separate, standalone codebase with its own `requirements.txt`.

For full requirements, constraints, database schema, data file formats, and build order, see [CLAUDE_CODE_BUILD_BRIEF.md](CLAUDE_CODE_BUILD_BRIEF.md).
