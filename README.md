# Group 10 Project — CS 112 Final Course Project

Three related, independent builds in one repo:

1. **[grid-analysis/](grid-analysis/)** — Python data science project analyzing a synthetic Ghana electricity grid dataset (pandas, NetworkX, Folium, Plotly, Streamlit). Includes a separate geospatial-analysis sub-pipeline at `grid-analysis/task_2_2_geospatial/`.
2. **[gridcare-lite/](gridcare-lite/)** — Python desktop app (Tkinter + SQLite) for utility outage/maintenance management.
3. **[clinicare-lite/](clinicare-lite/)** — Python web app (Flask + JSON files) for clinic patient admin and communication.

Each component is a separate, standalone codebase with its own `requirements.txt` and its own README with setup/run instructions.
