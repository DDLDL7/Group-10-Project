# Group 10 Project — CS 112 Final Course Project

Three related, independent builds in one repo:

1. **[grid-analysis/](grid-analysis/)** — Python data science project analyzing a synthetic Ghana electricity grid dataset (pandas, NetworkX, Folium, Streamlit). See also `grid-analysis/part_b/2.2/` for the geospatial-analysis sub-pipeline.
2. **[gridcare-lite/](gridcare-lite/)** — Python desktop app (Tkinter + SQLite) for utility outage/maintenance management. See also `gridcare-lite/part_b/Task 2.2/` for the geospatial-analysis sub-pipeline.
3. **[clinicare-lite/](clinicare-lite/)** — Python web app (Flask + JSON files) for clinic patient admin and communication.

Each component is a separate, standalone codebase with its own `requirements.txt`.
