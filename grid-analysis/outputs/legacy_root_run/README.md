# Archived outputs from an earlier pipeline layout

These files were found sitting at the repository root (not inside
`grid-analysis/` at all) with no corresponding source script checked in —
they match the output of the `scripts/task2_2_part*.py` geospatial
pipeline described in `Project_Plain_Guide.md`'s history, from a version
of the project structure that predates the current `grid-analysis/src/`
package. They're archived here rather than deleted, since they're still
valid evidence of that earlier work, but they are **not** produced by (or
required by) the current pipeline — see `../../REPORT.md` and
`../../dashboard.py` for the supported, current geographic analysis.
